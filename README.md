# pwc CLI

Public release source for the standalone, read-only Papers with Code command-line
client. It exposes paper search, metadata, Markdown, recent/trending/related
papers, lineage, and benchmark listing without authentication or mutation
commands.

See [`standalone_cli/README.md`](standalone_cli/README.md) for installation and
usage. Releases include checksum files and GitHub build-provenance attestations
for Linux x86-64, macOS Intel, and macOS Apple Silicon.
